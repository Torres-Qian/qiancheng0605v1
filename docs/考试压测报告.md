## 六、10000 行文件测试

| 指标 | 值 |
|------|-----|
| 文件 | 10000-orders.xlsx |
| 文件大小 | 4.43 MB |
| HTTP 状态 | **413** (FUNCTION_PAYLOAD_TOO_LARGE) |
| Blob 上传耗时 | 11195ms |

### 原因分析

Vercel Serverless Function 请求体限制 4.5MB，10000 行文件 4.43MB 加上 multipart 编码开销后超限。

### 解决方案

1. 升级 Vercel Pro 套餐（50MB payload）
2. 客户端分片上传
3. 改用对象存储直接上传（Vercel Blob 方案已验证）

## 九、结论

- ✅ 上传接口 P95 = 974ms，**满足 ≤ 1s 目标**

### 未达标项（1/13）
