## 六、10000 行文件测试

| 指标 | 值 |
|------|-----|
| 文件 | 10000-orders.xlsx |
| 文件大小 | 4.43 MB |
| HTTP 状态 | **413** (FUNCTION_PAYLOAD_TOO_LARGE) |

### 原因分析

Vercel Hobby 计划请求体限制 4.5MB，10000 行文件 4.43MB 加上 multipart 编码开销后超限。

### 解决方案

1. 升级 Vercel Pro 套餐（50MB payload）
2. 客户端分片上传
3. 前端 JSZip 压缩
