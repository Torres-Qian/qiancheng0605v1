| 表名 | 用途 | 关键索引 |
|------|------|----------|

| `import_task_batches` | 处理单元状态 | `task_id + unit_id` UNIQUE |
| `import_task_errors` | 行级错误明细 | `task_id + unit_id`, `error_code` |
| `event_outbox` | 可靠事件投递 | `status + next_retry_at` |
| `batch_performance_log` | 处理单元性能日志 | `task_id + unit_id` |
| `trace_events` | 全链路事件时间线 | `trace_id + occurred_at` |

## 七、错误码体系

| 错误码 | 含义 |
|--------|------|
| E001 | SKU 不存在 |
| E002 | 必填字段缺失 |
| E003 | 电话格式错误 |
| E004 | 数量不是正数 |
| E005 | 外部编码重复 |
| E006 | 规则映射失败 |
| E007 | 数据库写入失败 |
| E008 | 文件格式不支持 |

## 八、异步架构流程

```
用户上传 → API（≤1s 返回 task_id）
              ↓
         PostgreSQL（事务写入：import_tasks + event_outbox + batches）
              ↓
         Outbox Dispatcher（轮询 event_outbox）
              ↓
         BullMQ Queue（import-batch）
              ↓
         Worker（并发 4，限流 8/s）
              ├── 读取文件 → 规则引擎 → 批量 SKU 校验 → 批量 UPSERT
              ├── 行级错误 → import_task_errors
              └── 性能日志 → batch_performance_log
              ↓
         前端轮询（2s 刷新）→ 监控看板 / Trace 搜索
```

## 九、快速开始

```bash
# 1. 安装依赖
npm install

# 2. 配置环境变量（.env）
cp .env.example .env

# 3. 生成种子数据
npx tsx scripts/seed-data.ts

# 4. 启动开发服务器
npm run dev

# 5. 启动 Worker（另一个终端）
npx tsx src/lib/queue/worker.ts

# 6. 运行测试
npx vitest run

# 7. 运行压测
k6 run scripts/load-test.js
```
